# E-commerce-Delivery-Time-Prediction 🚚📦

## 🤔 Problem Statement 
An e-commerce company wants to improve delivery-time forecasting so that customers receive realistic delivery expectations and logistics teams can better plan operations. By predicting delivery duration accurately, the company can:
- Improve customer satisfaction
- Reduce late-delivery complaints
- Optimize logistics planning
- Enhance seller performance monitoring
- Lower operational costs

## 😉 Domain
- Logistics & Supply Chain Analytics

## 🎯 Objective
- The objective of this project is to develop a machine learning regression model that predicts the expected delivery time (in days) for an e-commerce order after the order has been approved and handed over to the carrier. The model will leverage historical order, customer, seller, and logistics data to provide accurate Estimated Time of Arrival (ETA) predictions.

## 📊 Dataset
- Source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
